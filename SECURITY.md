# Security Policy

## Development Status

Xelvra is under active development.

Security-sensitive changes require careful review.

## Reporting Vulnerabilities

Please do not disclose suspected vulnerabilities
through public GitHub Issues.

If GitHub Private Vulnerability Reporting is enabled,
use the repository's private security reporting feature:

https://github.com/MasFha/Xelvra/security/advisories/new

If private reporting is unavailable, do not publish
exploit details or sensitive information publicly.
Wait for a private reporting channel to be established.

## Sensitive Information

Never include:
- VPN server passwords.
- Private keys.
- Authentication tokens.
- Complete connection profile URIs.
- Unredacted application logs.
- Personal or private network information.

## Scope

Security reports may concern the Android VPN service,
Xray integration, profile storage, routing, and
application configuration.

No security audit or vulnerability response timeframe
is guaranteed by this document.
